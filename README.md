## 📖 Overview

This repository contains the source code for the personal developer portfolio of **Prachi Zala** — BCA Student, Python Developer, and AI & Data Analytics Enthusiast from Ahmedabad, India.

Engineered with performance, accessibility, and clean typography in mind, it delivers a smooth and lightning-fast user experience across all devices without relying on bulky third-party libraries or frameworks.

🔗 **Live Website:** [https://prachizala.github.io/prachi-portfolio/](https://prachizala.github.io/prachi-portfolio/)

---

## 🎯 Key Features

- **🌓 Dynamic Dark / Light Mode:** Automatically adapts to the visitor's system preferences using CSS `@media (prefers-color-scheme: dark)` and CSS Custom Properties.
- **📱 100% Responsive Design:** Fluid grid and flexbox layout engineered to look flawless on mobile phones, tablets, and high-resolution desktop monitors.
- **⚡ Zero Bloat & Instant Loading:** Built purely with Vanilla HTML5 & CSS3 — no npm packages, JavaScript overhead, or framework bundles needed.
- **🎨 Modern Typography:** Features a curated pairing of `Bricolage Grotesque` for bold display headings and `DM Sans` for readable body copy.
- **♿ WCAG Accessible:** Proper semantic markup (`<nav>`, `<section>`, `<article>`, `<footer>`), high-contrast color ratios, and visible `:focus-visible` indicators for keyboard navigation.
- **📄 Integrated Resume & Direct Contact:** Direct download link for `resume.pdf` alongside one-click email and LinkedIn connections.

## 🚀 Getting Started Locally

You don't need any complex build tools, node packages, or compilers to run this project.

### 1. Clone the repository
```bash
git clone https://github.com/prachizala/prachi-portfolio.git
cd prachi-portfolio
```

### 2. Open in your browser
- Simply double-click `index.html` in your file explorer, OR
- Using VS Code with the **Live Server** extension: right-click `index.html` and select **"Open with Live Server"**, OR
- Using Python local server:
  ```bash
  python -m http.server 8000
  ```
  Then visit `http://localhost:8000` in your web browser.

## 🛠️ Customization Guide

- **Change Theme Colors:** Modify the CSS variables inside `:root` (light mode) and `@media (prefers-color-scheme:dark)` in `index.html`:
  ```css
  --accent: #3B47D9;       /* Brand Primary Color */
  --paper: #F7F8FC;        /* Background Color */
  --ink: #151936;          /* Primary Text Color */
  ```
- **Update Profile Picture:** Replace `image/profile.jpeg` with your new photo keeping the same filename.
- **Update Resume:** Replace `resume.pdf` with your updated resume file.

## 🌐 Deployment (GitHub Pages)

This site is hosted for free using **GitHub Pages**:
1. Push your changes to the `master` (or `main`) branch.
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Branch**, select `master` / `/ (root)` and click **Save**.
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.
