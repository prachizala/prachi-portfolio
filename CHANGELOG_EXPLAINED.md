# Changelog Explained — Prachi Portfolio

This document explains all improvements made to the personal portfolio repository in simple language.

---

## 1. Portfolio Modernization (`docs: add portfolio README and open graph metadata`)

### What Changed:
1. **Added `README.md`**: Created complete documentation explaining the portfolio's purpose, live demo URL, technical highlights (performance, accessibility, dark mode), and local run steps.
2. **Added Open Graph & Twitter Card Meta Tags**: Configured `<meta property="og:...">` and `<meta name="twitter:...">` in `index.html` ensuring links shared on LinkedIn, WhatsApp, or Twitter display professional summary cards.
3. **Added SVG Monogram Favicon**: Embedded an inline SVG favicon directly into the HTML header so browsers display an icon without 404 errors.

### Why This Was Done (Interview Answer):
- A portfolio repo without a README looks abandoned to recruiters. Adding clear documentation and Open Graph tags demonstrates attention to detail and web standards compliance.
